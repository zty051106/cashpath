# CashPath · 钱径

**个人消费与还款决策沙盘，用金融方法比较支付成本、现金压力和收入变化后的承受能力。**

CashPath 面向有大额消费计划的个人：准备购买电脑、承担分期或支付租金时，将支付方案放入自己的收支日历，比较一次付清、固定分期和推迟购买的差别。

> 当前阶段：项目规划与仓库初始化。金融引擎、命令行工具和交互界面尚未实现。本文描述计划交付的能力。

## 项目目标

用户输入可用余额、收入与支出安排、支付方案和备用金底线。系统给出：

- 每种方案的名义总成本、现金流现值，以及适用时的实际年化资金成本。
- 计划期间的余额曲线、最低余额、首次资金缺口日期及原因。
- 收入延迟、收入下降和突发支出下的压力测试结果。
- 满足备用金与等待期限约束的方案，以及成本和现金余量之间的取舍。

## 核心金融方法

| 方法 | 用途 |
| --- | --- |
| 现值与 IRR / XIRR | 比较不同时间付款的成本，计算分期的隐含资金成本 |
| 流动性约束 | 按日期检查可用现金是否低于用户设置的底线 |
| 情景压力测试 | 模拟具体收支变化，展示缺口日期与金额 |
| 方案枚举与支配关系筛选 | 在有限的支付方式、购买日期中寻找可行方案，保留有取舍的候选 |

第一版用明确的压力情景。没有足够数据和概率假设时，不输出“违约概率”或“安全概率”。结论始终关联输入、假设和计算依据。

## 计划中的使用场景

1. **电脑购买**：比较现金付款、固定分期、下次发薪后购买，并检查是否影响房租及必要支出。
2. **已有分期下的新消费**：把已有还款纳入现金流，查看新增消费是否突破备用金底线。
3. **收入波动**：模拟工资延迟或报销晚到账，比较各支付方案的缺口和可调整空间。

## 第一版交付

- MoonBit 为主要实现语言的金融计算、现金流模拟和决策库。
- 可复现的命令行样例与机器可读的 JSON 报告。
- 用于填写条件、比较方案和查看余额曲线的轻量交互界面。
- 覆盖金额、日期、利率求解、压力情景和方案筛选的测试与 CI。
- 完整使用文档、开源许可证及 Mooncakes 包发布。

AI 自然语言录入作为后续增强；提取的金额、日期与条款需要用户确认，正式计算由金融引擎执行。
